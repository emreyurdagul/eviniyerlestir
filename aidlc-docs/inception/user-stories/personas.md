# EviniYerlestir - Kullanici Personalari

## Persona 1: Elif - Ev Sahibi (Birincil)

| Ozellik | Deger |
|---------|-------|
| **Yas** | 28-45 |
| **Rol** | Yeni ev sahibi / tasinen |
| **Teknik Seviye** | Orta (akilli telefon ve web kullanimi rahat) |
| **Motivasyon** | Yeni evine/odasina mobilya yerlestirmeden once planlamak |
| **Hedef** | Odanin boyutlarina uygun mobilya secimi, yerlesim duzeni deneme |
| **Hayal Kirikligi** | Mobilyayi alip eve getirdikten sonra sigmadigini gormek |
| **Kullanim Sikligi** | Ayda 1-2 kez (tasinma/dekorasyon donemlerinde yogun) |
| **Cihaz** | Masaustu + mobil (planlamayi PC'de, magazada kontrolu telefonda) |
| **Basari Kriteri** | 5 dakikada temel bir oda plani olusturabilmeli |

## Persona 2: Ahmet - Ic Mimar (Ikincil)

| Ozellik | Deger |
|---------|-------|
| **Yas** | 25-50 |
| **Rol** | Freelance ic mimar / dekorator |
| **Teknik Seviye** | Yuksek (AutoCAD, SketchUp deneyimi) |
| **Motivasyon** | Musteriye hizli konsept sunumu, olculu plan paylasimi |
| **Hedef** | Profesyonel gorunumlu kat plani + 3D gorsellestrme |
| **Hayal Kirikligi** | Karmasik yazilimlar icin lisans maliyeti, ogrenme egrisi |
| **Kullanim Sikligi** | Haftada 3-5 kez |
| **Cihaz** | Masaustu (buyuk ekran) |
| **Basari Kriteri** | Olculu 2D plan + 3D render uretip musteriye gonderebilmeli |

## Persona 3: MobiDeko A.S. - Mobilya Sirketi (Gelecek / Gelir)

| Ozellik | Deger |
|---------|-------|
| **Yas** | - |
| **Rol** | Mobilya uretici / satici sirket |
| **Teknik Seviye** | Orta-yuksek (e-ticaret, CRM deneyimi) |
| **Motivasyon** | Musterilerin urunlerini kendi evlerinde gorsellestirebilmesi |
| **Hedef** | Kendi mobilya modellerini platforma yukleyip musterilere sunmak |
| **Hayal Kirikligi** | Musterilerin "bu koltuk evime sigar mi?" sorusuna cevap verememek |
| **Kullanim Sikligi** | Surekli (embed / entegrasyon) |
| **Cihaz** | Web (iframe/embed olarak kendi sitesinde) |
| **Basari Kriteri** | GLTF model yukleme + marka bazli katalog olusturma |
